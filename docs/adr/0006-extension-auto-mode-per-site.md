# The extension runs by itself only on sites the user opted in

Auto-mode looks up the page's book after it loads, with no click. Running on every site would need install-time access to all of them (a scary warning and a stricter store review) and would read pages the user never asked about. So access is optional and per site: the card's "Автопошук на цьому сайті" link asks Chrome for that host (`www.` stripped, with subdomains, http and https), and the granted site permissions are the list. A registered content script (`autoStart.js`) covers only those sites, and only while the master switch in the options page is on. Nothing else changes: only the ISBN leaves the browser, to our own worker (ADR 0003), and the extension sends no usage stats (see `BACKLOG.md`). Auto-mode is silent while it looks and when it finds no ISBN; it shows a card, or the problem text, otherwise.
